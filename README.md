# Hourloom Support

Support and privacy pages for **Hourloom**, the time and pay ledger for iPhone, iPad and Apple Watch. English only (US App Store).

| File | Page |
| --- | --- |
| `index.html` | Support & FAQ |
| `privacy.html` | Privacy policy |
| `assets/style.css` | Shared styles (light & dark), shared with `tend-support` |

Plain HTML served by GitHub Pages from the `main` branch root, no build step. Intended home: `https://agoober.github.io/hourloom-support/` (create the `hourloom-support` repository and turn on Pages; the "Get help" and privacy contact links point at its issues, so they work only once it exists).

When the app's behavior changes in a way that affects data (network calls, new frameworks that read data, sync, sharing), update `privacy.html` and its dates, and the App Store privacy answers in `Hourloom/docs/APP_STORE.md`. No payroll, tax or legal claims anywhere.
